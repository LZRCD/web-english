# 词环 WordLoop 竞品对比与提升方案

> 数据来源：`docs/competitor-research/` 下 12 个主流背词产品的官网 / App Store 官方描述（crawl4ai 抓取 + iTunes API）。
> 结论：词环在 **原声校对音频、离线 ECDICT、AI 例句生成与反馈重写、义项考频、例句生词反向收录、FSRS+撤销、本地数据安全** 上已超过全部竞品。差距集中在**语境内容（真题/短文）、记忆方法（词根助记）、学习形态（测试/极速刷）、数据可视化（遗忘曲线/压力图）** 四类。

## 二、提升点清单（按优先级）

### P0 第一批：纯本地、低成本、高价值（无需 AI，2-3 天）

**P0-1 词汇量测试**（参考：墨墨/扇贝/沪江）
- 新增 `app/components/VocabTestView.tsx`，入口放欢迎页 + 词本页顶部。
- 算法：按红宝书词序分层抽样（每 100 词一层、每层抽 2-3 词，共约 60 题），自评「认识/不认识」+ 层位自适应（认识→更高层，不认识→更低层），估算词汇量。
- 结果页：估算词汇量 vs 考研目标（必考1856/基础3680/超纲1014 覆盖缺口），「不认识」的词一键加入薄弱词队列/临时学习队列。
- 纯本地实现，无 API。

**P0-2 极速刷词模式**（参考：扇贝极速刷词）
- 新增 `app/components/QuickReviewView.tsx`：全屏大字卡 + 释义 + 发音，可调速度（2s/3s/5s）自动翻卡，只保留「认识/不认识」两键。
- 认识→FSRS Good，不认识→Again（复用现有评分日志管线），结束后统计并一键把不认识词加入薄弱词队列。
- 入口：学习页设置区 / 词本「批量复习」旁。

**P0-3 文章批量提取生词**（参考：墨墨「提取一篇文章中所有单词」）
- 词本页新增「整篇提取」入口：粘贴文章 → 复用 `lib/word-utils.ts` 的英文分词 → 去重 → **过滤已掌握词（FSRS 状态）** → 列表预览释义（批量走 ECDICT lookup）→ 一键加入划词集/临时队列。

**P0-4 考义高亮 UI**（参考：不背「考义高亮/考点标记」）
- 现有义项考频（★高频/◐中频/·低频）已有数据，纯样式升级：高频义项加粗 + 浅底高亮，学习卡与查词弹窗一致生效。

**P0-5 每日学习提醒**（参考：多邻国/开心词场定时提醒）
- 设置页新增「学习提醒」区块：开关 + 时间选择 + 权限申请（Notification API，需用户手势触发）。
- 说明：纯本地应用，提醒仅在浏览器打开时生效（setInterval 检查），权限被拒显示引导文案。

**P0-6 遗忘曲线 + 复习压力图**（参考：墨墨三大图表）
- 轨迹页 `HistoryView.tsx` 新增两图（纯本地，复用现有统计管线）：
  - 遗忘曲线：按周统计到期复习中的遗忘率（Again+Hard 占比）与可提取率折线。
  - 复习压力：未来 30 天到期复习量堆积图（按 FSRS due 逐日统计），标注每日新词量线，直观看到积压。

### P1 第二批：需 DeepSeek，复用现有 AI 管线（3-4 天）

**P1-7 词根词缀拆解 + AI 助记**（参考：不背词根词缀、知米七种助记、墨墨助记库）
- 新增 `app/api/etymology/route.ts`（仿照 `sense-frequency` 的模式：DeepSeek 生成、IndexedDB 按词缓存、无密钥降级隐藏）。
- 返回 `{ breakdown, root, affixes[], mnemonic }`；WordCard 词族轨道下方新增「词根拆解 + 助记」卡片；划词弹窗复用。
- 词族轨道（派生树）已有，本次只补拆解与助记内容。

**P1-8 长难句每日一句**（参考：扇贝考研）
- 复用 AI 管线：DeepSeek 生成考研真题风格长难句 + 主干/修饰/从句结构拆解 + 参考译文，按日期缓存 IndexedDB。
- 展示：欢迎页或轨迹页顶部「今日长难句」卡片，离线显示缓存句。

**P1-9 短文填词（词文串学）**（参考：扇贝词文串学/短文填词）
- 新增 `app/api/cloze/route.ts`：输入当日新学词（≤10 个）→ DeepSeek 生成 80-120 词短文，目标词挖空，返回 4 选 1 干扰项（同词性/形近）。
- `QuizView.tsx` 新增「短文填词」题型，答对写 FSRS「认识」、答错写「忘记」并进薄弱词队列（复用现有专项测验管线）；按词组合 key 缓存。

### P2 第三批：需外部数据（按需推进）

**P2-10 考研真题例句库**（参考：不背 17 万真题例句、扇贝真题例句关联学习法）
- 数据准备：`scripts/build-kaoyan-examples.mjs`，输入历年考研真题阅读文本（用户自备/整理），自动提取含红宝书词的真题句 → 分片 JSON（`public/data/kaoyan-examples/`）。
- WordCard 学习卡优先展示「真题例句」卡片（带年份来源标签），与 AI 例句并列；例句生词同样进入反向收录。
- 这是考研场景含金量最高的内容，但强依赖数据源质量，故排第三批。

## 三、可直接粘贴的实现 Prompt

以下 prompt 按批次给出，可直接交给 Codex/其他编码 agent。**所有批次通用约束（每批 prompt 已内置，如需合并请保留）：**

```
项目：D:\me\小东西\单词（词环 WordLoop，个人考研背词站，Next.js + React + ts-fsrs，数据全在 IndexedDB，纯本地应用）
通用要求：
1. 只做本次任务描述的功能，不顺手重构无关代码；改动尽量小而集中。
2. 遵循现有代码风格：中文注释、与相邻文件相同的写法与组件模式。
3. AI 调用遵循现有模式（app/api/sense-frequency 为参考）：密钥缺失或调用失败时静默降级，不阻塞学习。
4. 新增测试：tests/ 下补对应单测；最后跑 npm run lint、npm run typecheck、npm run test:unit 全部通过并贴结果。
5. 不删除或迁移用户学习数据；IndexedDB 存储结构变更必须向后兼容（版本化迁移）。
6. 开发服务器固定端口 3000，遵守 AGENTS.md 的启动与验证规则。
```

### Prompt B（P1 第二批：3 个 AI 功能）


## 四、执行建议

1. **顺序**：先 Prompt A（纯本地、无风险、当天见效）→ 再 Prompt B（复用 AI 管线，注意降级）→ 最后 Prompt C（等数据备齐）。
2. **不建议做的**（对个人考研场景价值低）：图片记忆（百词斩，内容成本高）、游戏 PK/排行榜（无社交基础）、多端云同步（违背本地数据设计）、番茄钟/学习小组（非背词核心）。
3. **词环已领先、无需动的**：原声校对音频、离线词典、AI 例句反馈重写、义项考频、例句生词反向收录、FSRS+撤销、轨迹周报、性能诊断。
