# 第 25 轮后大方向审视

> 日期：2026-08-08 ｜ 分支：`codex/follow-up-hardening` ｜ 审视范围：第 21~25 轮

## 结论

- 第 21 轮补齐所有 review 动作进入时间线，核心 8 项咬合全部转为 ✅。
- 第 22~24 轮继续修复同类根因：lapse、慢回忆、三类测验从历史累计永久标弱，改为基于现有事件与恢复规则实时降级、复发再进入处置。
- 第 25 轮统一这些真实恢复状态的学习卡正向反馈，补齐“处置 → 验证 → 全态感知”最后一层。
- 所有改动均复用现有 state 派生，未新增持久化 schema，未触碰评分、FSRS 排程或备份链路；方向符合“垒金字塔、先验咬合”。

## 剩余缺口与边界

- “猜错”只有累计次数，没有事件时间与恢复记录。在不新增 schema 的边界下无法可靠降级或写入时间线，继续明确排除，不能伪造恢复。
- 顽固词的 `active` 是当前标记/自动判定状态，退出不等同于一次可证明的学习恢复，暂不纳入“已稳定”维度。
- 现有复发追踪只展示上周冲刺解决词截至当前的状态，缺少多周处置批次对比；这是仍有中高价值且可与已有层咬合的候选。

## 第 26 轮决策

- 新增最近 4 个冲刺周的复发率回溯：按冲刺发生周分组已解决词，再以当前统一薄弱画像判断各批词截至当前是否复发。
- UI 与文档必须明确这是“按处置周分组、截至当前回溯”，不是历史周末状态快照；不得用当前 state 伪造过去时点画像。
- 第 26 轮完成后执行整体评估：若除受 schema 边界阻塞的猜错外无中高价值断链或联动层，则触发收尾，不为轮数继续打磨。
