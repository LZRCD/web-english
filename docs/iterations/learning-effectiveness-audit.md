## 第 34 轮修正证据

修改前，同词只要在多个周各有一次冲刺 `rating≥2`，就会同时进入多个周 cohort，4 周展示跨周重复样本；页面又把当前统一薄弱画像写成“复发”，暗示已经恢复后发生了新的历史事件。

修改后：

- 多周序列按 wordId 只归最近一次达标处置周，输入 review 顺序不影响归属。
- UI 统一使用“当场达标”“当前仍薄弱”“当前仍薄弱率”。
- UI 明示“未区分从未恢复与恢复后再次薄弱”。
- 既有单周派生接口、当前仍薄弱词明细和再次冲刺动作保留；不改评分、FSRS、恢复判定或数据写入。

## 后续阶段 A 缺口

1. “解决词数”仍超过 `rating≥2` 的证据，应单轮改为“当场达标词数”。
2. “回忆降幅/提升”仍是非配对事件均值，应单轮改为同词配对观察或降级文案。
3. 4 周冲刺成效继承以上两项限制；在修正前不能作为效果结论。
