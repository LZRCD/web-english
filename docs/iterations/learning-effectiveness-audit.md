## 第 34 轮修正证据

修改前，同词只要在多个周各有一次冲刺 `rating≥2`，就会同时进入多个周 cohort，4 周展示跨周重复样本；页面又把当前统一薄弱画像写成“复发”，暗示已经恢复后发生了新的历史事件。

修改后：

- 多周序列按 wordId 只归最近一次达标处置周，输入 review 顺序不影响归属。
- UI 统一使用“当场达标”“当前仍薄弱”“当前仍薄弱率”。
- UI 明示“未区分从未恢复与恢复后再次薄弱”。
- 既有单周派生接口、当前仍薄弱词明细和再次冲刺动作保留；不改评分、FSRS、恢复判定或数据写入。

## 第 35 轮修正证据

- `buildSprintEffectiveness.resolvedCount` 仍严格来自本周 `sprint:*` review 中 `rating≥2` 的 wordId 去重；`buildSprintCompletionSummary.resolvedCount` 与冲刺历史 `successCount` 是单次 session 的相同口径。
- 周报标题、指标、4 周说明、每周卡片、冲刺完成页和冲刺历史成功率共 6 个用户入口统一改为“当场达标”；内部字段、评分条件、去重和数值断言均保留。
- “仍需关注”继续来自当前统一薄弱画像，允许与当场达标词重叠；未把它改写成“未达标”。

## 第 36 轮修正证据

- 新增共享纯函数 `buildPairedRecallChange`：目标侧按 wordId 聚合全部合法测时后取词内均值；基线侧只选严格早于边界的最近一条非冲刺合法测时；两侧都有样本才进入配对词分母，最后跨词等权。
- 周报与 4 周趋势的目标事件是对应本地周窗内全部 `sprint:*` review，边界是该窗第一个冲刺事件；完成页目标事件是完整 session 的 review，边界是 `session.createdAt`。两入口共享同一配对规则但保留各自真实目标窗。
- 完成页基线明确排除历史 `sprint:*`；不改写任何历史 review。无配对返回 `pairedWordCount=0` 且两个均值与变化均为 `null`，三个入口均显示“无配对样本”。
- 用户文案统一为“冲刺观察 / 同词配对回忆变化 / 较此前快或慢”，明确配对词数；删除“提升/降幅/冲刺后”因果或时序暗示。
- 纯函数测试覆盖同词两侧、目标词内多事件、跨词等权、最近非冲刺基线、历史冲刺排除、无配对、缺失/非法测时、严格边界和乱序输入；周报、4 周与完成页均有集成/E2E 证据。
- 历史 `recallMs` 覆盖不足只会减少配对样本并诚实显示无样本；没有补写、回填或伪造测时。

## 第 37 轮修正证据

- `LearningInsights.successRate` 从 `number` 改为 `number | null`；当前窗无评分事件时返回 `null`，有合法事件但全部 `rating<2` 时仍返回真实 `0`。`successRateDelta` 仅在当前窗和上一窗都有事件时计算，单位明确为百分点。
- 统计规则不变：当前窗为本地当天向前共 7 个自然日的 00:00 至 `now`，上一窗为紧邻的前 7 个自然日且右边界不含当前窗起点；未来和无效时间排除。
- 分子仍为 `rating≥2` 事件数，分母仍为窗内全部评分事件数；不按词去重，每事件一票，同词重复以及 new/review/sprint、普通/冲刺 session 混合均保留。
- 轨迹页改为“评分达标占比”，披露“`rating≥2 / 全部评分事件`”和“近 7 天截至目前”。当前无样本显示“— / 当前窗无样本”，真实 0 显示 `0%`；两窗都有样本时显示“较上窗 ±N 个百分点”或“较上窗持平”，上一窗无样本显示“无可比上窗”。
- 该比较只是两个事件总体占比之差，不做同词配对，不假设两窗构成一致，也不写成提升、下降原因或学习成效。
- 单测覆盖当前无样本且上一窗有样本、真实 0 且上一窗有/无样本、真实 100%、同词多事件、混合会话、本地窗口左右边界、未来和无效时间；E2E 覆盖无样本、真实 0、百分点差与持平用户入口。

## 第 38 轮 B1/B2/B3 证据

- 只读审计确认现有 `ReviewEvent` 已有稳定的事件 id、词 id、发生时间、评分、可选 sessionId 与可选 recallMs；普通 review 可由“非 `sprint:*`”识别。`quizAttempts` 是独立数组，不会进入仅消费 reviews 的观察函数，因此无需 schema/version/store/domain。
- B1：最近 4 个完整周内，每个 wordId 只选 `(reviewedAtMs,id)` 总序上最近一次 `rating≥2` 的 sprint review 为锚点，并归入该锚点所在周。锚点后同词第一条 review 若仍为 sprint（任意评分、任意 sprint session）即截断；否则该非 sprint review 是首次随访。`quiz:*` review 和无 sessionId 旧 review 均可随访，不能排除。
- B2：cohort、已观察、未观察、截断与保持词数分别披露；覆盖率分母是 cohort，保持率分母仅是已观察词。未观察（含截断）不充当失败。cohort 空周返回 `null`；已观察为 0 时保持率与平均间隔为 `null`，真实 0% 保持率保留。
- B3：只有锚点与已配对随访两侧 `recallMs` 都是有限且 `>=0` 的词进入测时分母；两侧均值先词级配对后跨词等权，变化为“随访 − 冲刺”。评分保持分母与测时分母独立，缺失/非法测时不撤销已观察事实。
- 页面在当前仍薄弱区后展示“冲刺后首次正常复习保持 4 周”，逐周披露 cohort、覆盖、保持、未观察、截断、实际平均间隔、配对测时数和两侧均值；文案持续标注观察性，不声称导致、恢复或掌握。
- 单测覆盖成功/失败随访、无后续、下一 sprint 成功/失败截断、跨周最近锚点、同 session 多事件、quiz review 答对/答错、quiz review 与下一 sprint 先后、只有 quizAttempt、同毫秒总序、乱序、非法/未来时间、空 cohort、零观察与合法/非法测时。

## 阶段 A/B 结论与阶段 C 入口

1. 阶段 A 完成：冲刺活动量、当场达标、同词配对回忆观察、截至当前仍薄弱，以及近 7 天全局评分事件占比，现已在分子、分母、时间窗、权重、空样本与不能证明的结论上明确分开。
2. 阶段 B 的 B1 cohort/截断、B2 覆盖/保持与 B3 配对测时已在同一权威纯函数和同一用户入口闭环；没有跨新冲刺、没有把未观察算失败，也没有把 quizAttempt 当 review。
3. 猜错仍只有累计次数，没有真实事件时间、恢复或复发数据源；禁止伪造，但不阻止阶段 A/B 的诚实口径完成。
4. 下一轮只进入阶段 C“未来处置维度归因”的只读审计：严格复用现有结构化 `sprint:*` sessionId，先证明能否无歧义连接处置维度与未来首次正常 review；不新增 schema、不回填历史、不先实现分维度报告或自适应。
