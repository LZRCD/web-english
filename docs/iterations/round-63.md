## 推荐契约

将 `activeQuiz` 定义为“可恢复的测验快照”，而不是不可变的历史成绩档案。恢复必须等持久化状态 hydrate 且词库 ready 后执行；不得把加载中的空词库判成题目全部失效。

### 部分题目失效

| 项目 | 推荐行为 |
|---|---|
| 有效性 | 目标词必须仍同时存在于当前词库和学习进度；失效目标从可继续题组移除。 |
| 题序 | 剩余题保持原 `questionWordIds` 相对顺序与各自原 seed 偏移，不重新参与推荐、优先级或随机排序。 |
| index | 把旧 index 视为原题组的当前题边界；新 index 等于该边界之前仍有效的题数，并夹取到新题组范围。这样前题失效不会跳过原当前题，当前题失效则落到下一道有效题。 |
| 用户作答快照 | 活跃会话只保留仍有效题目的已提交答案，原提交文本与提交时 `correct` 不重判；失效题目的活跃答案随题移除，但已经写入的 `quizAttempts` / review 事实不撤销、不改写。 |
| correctCount | 不沿用旧累计值；按保留下来的已提交答案中 `correct=true` 的数量重算。 |
| 完成状态 | 不原样沿用旧 `complete`；有至少一道有效题且所有剩余题均已有提交答案时为完成，否则继续。若删除的是唯一未答题，可直接进入按剩余题计算的结果页。 |
| 结果分母 | 统一使用恢复后的有效题数；分子、分母和完成状态来自同一有效题集合，不允许超过 100%。 |
| 刷新写回 | 在 ready 门禁后一次性写回修正后的题组、index、answers、correctCount 和 complete；第二次刷新应无额外变化。不得在词库未 ready 时写回或清除。 |
| 用户提示 | 显示一次非阻断提示：“本组有 N 题因词条更新无法继续，已保留其余 M 题；结果按剩余题目计算。”提示必须说明题目减少及计分分母变化。 |

### 全部题目失效

- 清除 `activeQuiz`，不保留一个当前产品没有可执行恢复入口的陈旧会话；已落盘的 `quizAttempts`、review、FSRS 与薄弱信号事实不回滚。
- 测验页进入模式选择态，并提供清晰的“重新开始测验”入口；不自动选择模式或自动开始新题组。
- 显示一次说明性提示：“本组题目已不可用，已结束本组；既有测验记录不受影响，可以重新开始。”语义必须同时覆盖结束原因、历史记录未被清除和下一步。
- 清除写回必须在 hydrate 与词库 ready 后发生，并保证再次刷新不重复恢复或重复提示旧会话。

## “答案快照”的推荐范围

推荐把承诺分成两层：

1. **作答事实快照**：保存用户已提交的答案文本与提交当时的正确性；恢复时不根据后来变化的词条重新判分。这一层只对恢复后仍有效的题进入活跃会话统计，失效题的既有 attempt / review 仍作为历史事实保留。
2. **题目呈现快照**：对恢复后仍有效的题，同时保证原题干、正确答案以及 `meaning-choice` 选项与顺序不变。否则删除其他词也可能改变干扰项，用户会在同一测验中看到刷新前后不同的题目，和“可恢复快照”的语义冲突。

第二层超出现有 `questionWordIds + seed` 能力，预计需要扩展持久化会话结构及其 normalize、分域往返、备份/导入、跨标签合并、清空与兼容测试。是否需要 schema/version 或 store/domain 变化、旧会话如何降级，必须在产品批准后另行审计；本轮不设计字段、不设计迁移，也不实施任何结构变化。

## 备选方案与主要取舍

| 方案 | 主要收益 | 主要代价 | 建议 |
|---|---|---|---|
| 推荐：有效题精确恢复 + 完整题目呈现快照；全部失效清除 | 续答价值、计分一致性和刷新公平性同时成立；用户知道分母变化 | 需要评估并授权持久化结构扩展与旧会话兼容 | **推荐，待批准** |
| 最小方案：只快照已提交答案，剩余题继续用当前词数据重建 | 可继续沿用现有结构，改动面较小 | 题干、正确答案或干扰项可能变化；同一会话刷新前后并非同一套题 | 仅在产品明确接受内容漂移时选择 |
| 保守方案：发现任一失效即清除整组并重开 | 状态和计分最简单，不会展示漂移题目 | 一个失效词会丢弃其余有效题的续答进度，恢复价值最低 | 适合不愿扩展持久化结构时的安全退路 |
| 保留陈旧会话等待恢复 | 不主动删除 activeQuiz | 当前没有恢复入口，会重复尝试并隐藏失败；用户无法完成或处理该会话 | 不推荐 |
