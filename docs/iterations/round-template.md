# 第 N 轮：唯一目标标题

- 日期：YYYY-MM-DD
- 分支：`实际分支`
- 起始 HEAD：`完整提交哈希`
- 状态：等待授权 / 进行中 / 完成 / 部分完成 / 停止

## 授权与唯一目标

- 用户授权：引用本轮等价指令。
- 问题：只写一个用户可见问题、风险或待证伪判断。
- 完成定义：写成可判定的结果。
- 允许范围：列出职责或精确文件。
- 禁止范围：列出不得顺手处理的相邻问题。
- 停止条件：列出需要新授权或证据不足的情况。

## Round 0 现场

- 分支与 HEAD：
- tracked 工作区：
- 暂存区：
- 保护项：`1.txt`、`.zcode/`、架构文档、轮次/服务日志均未修改或暂存。
- 端口/PID：不涉及浏览器时写“不启动服务”；涉及则登记固定端口 `3000` 的监听与归属。
- 既有调用链与测试入口：
- STOP/GO：结论及证据。

## 实施或审计

### 证据链

描述数据/事件如何从产生位置流到最终消费位置，以及现有测试已覆盖和未覆盖的边界。

### 最小变更

- 文件：变更及其与唯一目标的对应关系。
- 范围外发现：只记录，不修复。

只读审计轮将本节改为“审计结果”，不得混入实现。

## 验证

| 命令或检查 | 结果 | 能证明 | 不能证明 |
|---|---|---|---|
| `具体命令` | 通过/失败及数量 | 当前证据 | 未覆盖边界 |

- 超时/重试：无；若有，记录中断时间、原因和重试结果。
- 浏览器服务：未启动；若启动，记录端口、PID、健康检查和清理结果。
- 历史证据：只作背景，不冒充本轮验证。
