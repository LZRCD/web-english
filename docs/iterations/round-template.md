# 第 N 轮：唯一目标

- 日期：YYYY-MM-DD
- 分支 / 起始 HEAD：`branch` / `hash`
- 批次：名称；第 X/Y 轮
- 状态：完成 / 部分完成 / STOP

## 目标与边界

- 问题与完成定义：
- 允许修改：
- 禁止修改：
- Delta Gate：HEAD、tracked/index、保护项、端口归属均符合预期；若触发完整 Round 0，说明原因。

## 改动

- `文件`：改动及其与目标的关系。
- 范围外发现：无；若有，只记录候选，不在本轮修复。

## 验证

| 级别 / 命令 | 结果 | 证据边界 |
|---|---|---|
| `Vn / 命令` | 通过/失败、数量、耗时 | 能证明什么；不能证明什么 |

- 服务：未启动；或固定 `3000` 的复用、PID、日志和清理结果。
- 生成文件：无漂移；或已在最终暂存前恢复。

## 提交与判断

- 实际修改 / 精确暂存：
- `git diff --check` / PreCommit：
- 提交：`hash 中文标题`；本文件不预猜自身提交 hash。
- 下一步：继续 / 转向 / 收尾 / 等待授权；理由：
- push：未执行。

若 STOP，补充：已完成、未完成、停止原因和准确恢复入口。
