## 3. 整合路线图（只含真实缺口）

### P0 纯本地（2-3 天，当天可见，无外部依赖）

| # | 事项 | 做法 | 复用 / 依据 |

| 1 | **考义高亮样式** | WordCard 义项区与划词弹窗：★义项加粗 + 浅底；不改数据结构 | 数据已就绪（`SenseFrequencyMap`） |
| 2 | **词汇量测试** | 新增 `VocabTestView.tsx`；按红宝书词序分层抽样（每 100 词层抽 2-3 词），「认识/不认识」自评 + 层位自适应；结果页对比考研目标（必考 1856 / 基础 3680 / 超纲 1014）；「不认识」一键加入临时学习队列 | 词表数据源 `lib/redbook.ts`；入口：欢迎页 + 词书页顶部 |

| 6 | **遗忘曲线 + 复习压力图** | HistoryView 新增两图：按周遗忘率（Again+Hard 占比）与可提取率折线；未来 30 天 FSRS due 逐日堆积 + 每日新词量线 | 数据全部来自现有 `reviews` + `fsrsCards`；口径按 True Retention（见 P0-7） |

### P0-7 口径补强（与 6 同一批次，先于图表落地）

- `buildTrueRetention` 派生查询：仅计影响调度的复习事件；ease==1（Again）记失败、其余成功；young(<21天)/mature(≥21天) 分桶。
- 周报 `successRate`（`lib/insights.ts:93`）保持现有 rating>=2 口径不动，新指标与旧指标并存并注明口径，避免回归。
- **可选架构补强**（低风险、不阻塞）：`ReviewEvent` 追加 `intervalBefore / difficultyAfter` 快照字段，IndexedDB 版本化迁移；为将来回放与更细统计预留。非任何功能的前置依赖。

| # | 事项 | 做法 |

### 可选（排 AI 之后，按需）

- 极速刷词 UI（复用冲刺管线，仅加全屏大字 + 自动翻卡 + 两键层）
- 看义默写独立模式 + 字母级错误统计（`timing[]` / `mistakes`，与四档评分并存）
- 错词队列换排序权重（错误次数 0.6 + 最近错误时间 0.4）

### 不做（与两份调研结论一致 + 本地定位）

- 云同步 / PWA 真离线 / 多端强绑定（导出 JSON 已覆盖备份诉求）
- 图片记忆、PK 排行、番茄钟、学习小组
- Anki 式 Filtered/Preview/Cram 状态机（冲刺已用事件 + 过滤查询建模）
- 通知内快速测试（纯本地 Web 受浏览器权限限制，先做提醒 + 点击跳转）

## 4. 执行顺序与依赖

1. **P0-7 口径补强**（半天，先于图表）——遗忘曲线与周报诚实化的前提，只动 `lib/insights.ts` 与派生查询，无 schema 变更风险。

每批完成后跑 `npm run lint`、`npm run typecheck`、`npm run test:unit`，补 `tests/` 单测（AI 批次含降级路径测试）。
