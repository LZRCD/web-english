## 0. 结论速览

1. **定位**：功能补 A（竞品的内容与学习形态），地基补 B（开源的数据与统计范式）。A 回答"补什么"，B 回答"怎么建得对"，不冲突。
2. **已领先、保持不动**：原声校对音频、离线 ECDICT 划词、AI 例句与反馈重写、义项考频、例句生词反向收录、FSRS、本地数据安全、轨迹周报（含"当场达标"口径）、三步引导。
3. **已落地、不再重复**：薄弱画像四件套（`lib/weak-signals/`）、追加式复习日志、4 条 AI 管线（coach/enrich/lookup/sense-frequency，含缓存与降级）、防泄题模板化、冲刺会话管线。
4. **差距集中在**：语境内容（真题/短文）、记忆方法（词根助记）、学习形态（测试/极速刷/打字）、数据可视化（遗忘曲线/压力图）、工程补强（事件分层谓词、lapse 快照、leech 复发、续练、任务长度可选）。
5. **执行顺序**：T0 地基补强（低风险小改）→ T1 纯本地 6 项 → T2 AI 3 项 → T3 体验 4 项 → T4 可选导出。

## 4. 各批次详情

### T0 地基补强（先于一切，低成本高杠杆）

**T0-1 事件分层谓词**〔源 P0 + 遗 ISSUE-01〕
- 目标：统计口径诚实化。现状 `ReviewEvent.kind` 只有 new/review，查词/猜错无独立事件层。
- 改动：`kind` 扩展为分层——`review`（推进 FSRS、影响调度）与 `lookup` / `guess_mistake`（只记账）两层；统计一律按 `kind='review'` 过滤，查词/猜错排除在成功率之外。
- 新增 `buildTrueRetention` 派生查询：口径参考 Anki True Retention——仅计影响调度且（Review 或 lastIvl≥1 天）的事件，ease==1 记失败其余成功，young(<21天)/mature(≥21天) 分桶。
- 冲刺中的复习事件带 `session_id` 扩展字段（现有 `sessionId` 复用），不新增持久状态机。

**T0-2 复习事件快照字段**〔源 P0〕
- `ReviewEvent` 补 `intervalBefore / difficultyAfter`（写库前快照"新旧间隔"，type 取答题前状态），回放无需猜测语义。
- 历史数据用现有字段回填初始化，不丢数据、不做整表重构。

**T0-3 评分文案与口径披露**〔遗 ISSUE-01〕
- 评分引导语改为"请依据查看释义前的回忆状态评分"，四档各附一句中文判定说明。
- `rating>=2` 只等于"当场达标"，页面不表述为掌握/恢复/长期记住；周报/图表与 T0 谓词同源。

### T1 第一批：纯本地、低成本、高价值（无需 AI）

**T1-1 词汇量测试**〔竞 P0-1〕
- 新增 `app/components/VocabTestView.tsx`，入口放欢迎页 + 词本页顶部。
- 按红宝书词序分层抽样（每 100 词一层、每层抽 2-3 词，共约 60 题），自评"认识/不认识" + 层位自适应。
- 结果页：估算词汇量 vs 考研目标（必考 1856 / 基础 3680 / 超纲 1014）覆盖缺口，"不认识"一键加入薄弱词队列/临时学习队列。纯本地，无 API。

**T1-2 极速刷词模式**〔竞 P0-2，复用冲刺〕
- 新增 `app/components/QuickReviewView.tsx`：全屏大字卡 + 释义 + 发音，速度可调（2s/3s/5s）自动翻卡，只留"认识/不认识"两键。
- 认识→FSRS Good，不认识→Again（复用现有评分日志管线），结束后统计并一键加入薄弱词队列。
- 入口：学习页设置区 / 词本"批量复习"旁。**不建第二套调度**：复用冲刺会话与 `buildSprintWordIds` 选词。

**T1-3 文章批量提取生词**〔竞 P0-3〕
- 词本页新增"整篇提取"：粘贴文章 → 复用 `lib/word-utils.ts` 英文分词 → 去重 → **过滤已掌握词（FSRS 状态）** → 列表预览释义（批量 ECDICT lookup）→ 一键加入划词集/临时队列。

**T1-4 考义高亮 UI**〔竞 P0-4〕
- 现有义项考频（★/◐/·）数据已就绪，纯样式升级：高频义项加粗 + 浅底高亮，学习卡与查词弹窗一致生效，不改数据结构。

**T1-5 每日学习提醒**〔竞 P0-5〕
- 设置页新增"学习提醒"区块：开关 + 时间选择 + Notification 权限申请（需用户手势触发）。
- 说明：纯本地应用，提醒仅在浏览器打开时生效（setInterval 检查）；权限被拒显示引导文案；通知点击跳学习页。通知内快速测试留远期（浏览器限制）。

**T1-6 遗忘曲线 + 复习压力图**〔竞 P0-6，口径依赖 T0〕
- 轨迹页 `HistoryView.tsx` 新增两图（纯本地，复用现有统计管线）：
  - 遗忘曲线：按周统计到期复习遗忘率（Again+Hard 占比）与可提取率折线；
  - 复习压力：未来 30 天到期复习量堆积图（按 FSRS due 逐日统计）+ 每日新词量线。
- 口径按 T0 事件分层谓词过滤；与周报数值同源，不得出现两套数字。

### T2 第二批：需 DeepSeek，复用现有 AI 管线

**T2-1 词根词缀拆解 + AI 助记**〔竞 P1-7〕
- 新增 `app/api/etymology/route.ts`（仿照 `sense-frequency` 模式：DeepSeek 生成、IndexedDB 按词缓存、无密钥降级隐藏）。
- 返回 `{ breakdown, root, affixes[], mnemonic }`；WordCard 词族轨道下方新增"词根拆解 + 助记"卡片；划词弹窗复用。
- 助记必须正面、贴合考研词义。

**T2-2 长难句每日一句**〔竞 P1-8〕
- 复用 AI 管线：DeepSeek 生成考研真题风格长难句 + 主干/修饰/从句结构拆解 + 参考译文，按日期缓存 IndexedDB（当天只生成一次）。
- 展示：欢迎页顶部"今日长难句"卡片（含朗读），离线显示缓存句。

**T2-3 短文填词（词文串学）**〔竞 P1-9〕
- 新增 `app/api/cloze/route.ts`：输入当日新学词（≤10 个）→ 生成 80-120 词短文，目标词挖空，返回 4 选 1 干扰项（同词性/形近，不得含目标词变形）。
- `QuizView.tsx` 新增"短文填词"题型：答对写 FSRS"认识"、答错写"忘记"并进薄弱词队列（复用现有专项测验管线）；按词组合（排序后拼接）key 缓存。
- 挖空参照沙拉查词 `%contextCloze%`（正则转义 + 等长下划线）；题目界面答案永不直接出现。

### T3 第三批：学习体验与数据

**T3-1 考研真题例句库**〔竞 P2-10，等数据〕
- 数据准备：`scripts/build-kaoyan-examples.mjs`，输入历年考研真题阅读文本（用户自备 `scripts/kaoyan-corpus/`，当前不存在）→ 提取含红宝书词的真题句 → 分片 JSON + 索引 manifest。
- WordCard 优先展示"真题例句"卡片（带年份来源标签），与 AI 例句并列；例句生词同样进反向收录。
- 强依赖数据源质量，故排第三批。

**T3-2 复习会话续练**〔源 P2 + 遗 ISSUE-04〕
- 参照 qwerty-learner `reviewRecords`：`{words, index, isFinished, createTime}` 持久化，中断可"继续当前进度"。
- 与"任务长度可选（5/10/15/20）"配套（默认 10）。

**T3-3 打字/默写模式 + 字母级错误**〔源 P3，🟡 可选〕
- 参照 qwerty-learner：`timing[]`（每字母耗时）、`mistakes {字母下标: 按错的键}`——给"拼写薄弱"维度提供客观信号。
- 默写成绩折算：全对=Good、错 1 次=Hard、错 2 次+=Again。

**T3-4 错词加权队列**〔源 P2〕
- 错误次数(0.6) + 最近错误时间(0.4) 加权排序生成"优先复习"列表；与薄弱画像互补（画像=哪些词弱，队列=下次先练哪些）。

**T3-5 leech 阈值复发（补强 weak-signals）**〔源 P1〕
- 遗忘即降级：Again → `lapses += 1`、难度上升 → Relearning 短间隔 → 走完步进回 Review，间隔硬性压回 1 天。
- 复发检测：`lapses >= 8` 且每过半阈值再触发（8, 12, 16, 20…）→ 打 `leech` 标签（= 薄弱词集，用户可见、可手动移除）。
- 数据模型：`{lapses 总数, 最近 lapse 时间, 当前连续成功次数}` 三元组；**入口接既有 `lib/weak-signals/` projection，不新增双源存储**。

### T4 第四批：可选 / 长期

**T4-1 数据导出**〔源 P3〕
- 设置页放"导出学习数据 JSON"与"导出本周生词"；模板化占位符（`%text% %trans% %context% %contextCloze% %note% %date%`）。
- PWA 真离线 / 全量快照同步：**暂不做**（违背纯本地定位）；同步只做数据模型预留（稳定 UUID + updatedAt，将来接快照备份时低迁移成本）。

## 5. 执行顺序与依赖

1. **先 T0 后 T1**：遗忘曲线/压力图（T1-6）与 leech（T3-5）的口径都依赖事件分层谓词；T0 是小改（补字段 + 谓词），不是大迁移。
2. **T1 紧接 T0**：纯本地、无风险、当天见效。
3. **T2 再上**：复用 AI 管线，注意三层降级（LLM → IndexedDB 缓存 → 本地模板/规则），AI 是可选增强层不是数据通路。
4. **T3 依数据与意愿推进**：真题例句库等 `scripts/kaoyan-corpus/` 备齐；续练与错词队列可独立并行；leech 阈值依赖 T0 快照。
5. **T4 长期**：导出可随时做；同步只做模型预留。

## 6. 不做清单（对个人考研场景价值低）

- 图片记忆（内容成本高）
- 游戏 PK / 排行榜（无社交基础）
- 多端云同步强绑定（违背本地数据设计）
- 番茄钟 / 学习小组（非背词核心）
- Anki 式完整 Filtered/Preview/Cram 状态机（冲刺用事件 + 过滤查询即可）

## 7. 实施契约（每次批次落地时）

- 本文为只读方案；后续任一批次实施需按 `docs/iterations/AUTOMATION-SOP.md` 重新授权并执行 Round 0。
- 每个批次一个目标、精确暂存、一个中文提交、不 push；不删/不迁移用户学习数据；IndexedDB 结构变更必须版本化迁移、向后兼容。
- 新增测试补 `tests/`；验收跑 `npm run lint`、`npm run typecheck`、`npm run test:unit` 并贴结果。
- 开发服务器固定端口 3000，遵守 AGENTS.md 启动与验证规则。
- 保护项：`1.txt`、`2.txt`、`.zcode/`、架构文档、Typora 日志和历史运行日志不得暂存或修改。
