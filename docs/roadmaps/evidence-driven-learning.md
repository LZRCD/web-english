# 证据驱动学习系统长期路线

日期：2026-08-08
起点：`b645196`（`codex/follow-up-hardening`）

## 总目标

在不夸大因果效果的前提下，把既有“薄弱发现 → 处置 → 真实结果回流”闭环推进为可解释、可随访、可维护的学习系统。所有统计先说明数据源、样本、时间窗与不能证明的结论，再决定是否进入产品界面。

## 阶段路线

| 阶段 | 唯一主题 | 进入条件 | 交付门槛 |
|---|---|---|---|
| A | 成效口径诚实化 | 复用既有 reviews / quizAttempts / 统一薄弱画像 | 七项指标审计完整；每轮只修一条最高价值口径；活动量、当场表现、后续保持、当前仍薄弱明确分开 |
| B | 冲刺后首次正常复习保持 | A 完成；无需新增 schema | 冲刺达标 review 后只取首次非冲刺 review；再次冲刺截断；未随访不进失败分母；回忆耗时按同词配对 |
| C | 未来处置维度归因 | B 完成；现有 sessionId 足以结构化表达 | 只标注未来真实入口；旧 session 统一为未标注/通用；不反推历史，不改评分或 FSRS |
| D | 分维度观察报告 | B、C 均完成且存在真实随访样本 | 每个维度同时显示样本数、随访覆盖、保持结果、实际间隔和配对耗时；不排名、不声称因果 |
| E | 自适应推荐可行性评估 | 各维度归因与随访样本充分 | 默认只产出设计报告；任何推荐行为变更必须另获用户批准，并可关闭、可回退、不改 FSRS |
| F | 稳定维护与发布准备 | A~E 的已授权范围完成或明确停止 | lint、typecheck、全量测试、核心 E2E、兼容性与发布清单通过；无端口/构建残留 |

## 永久证据边界

- `rating≥2` 只表示该次冲刺当场评分达标，不等于长期解决。
- 当前统一薄弱画像是当前状态，不能自动还原任一历史时点。
- 没有冲刺后的正常复习记录时，保持结果是未观察，不是失败。
- 猜错只有累计次数，缺少真实事件时间；不构造恢复、复发、随访或维度归因。
- 不用两组不等样本总体均值声称同词提升，不把观察性相关写成训练因果。
