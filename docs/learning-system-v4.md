# 词环 v5 FSRS 学习系统总纲

## 目标

在保留“学习、词书、词本、轨迹、设置”五个现有页面和主动回忆卡片的前提下，建立完整的学习闭环：

1. 评分事件负责可追溯的学习历史。
2. 单词记忆状态负责描述当前掌握程度和下次复习时间。
3. 学习会话负责决定当前队列、顺序和进度。

红宝书音频使用“原文件 + 时间索引”，低置信切片自动回退浏览器 TTS。

## 核心模型

### 评分事件 `Review`

- 每次有效评分生成唯一事件。
- 记录评分发生时它属于新学还是复习。
- 日历、每日明细和完成次数从评分事件计算。
- 撤销只删除目标事件，不依赖“数组最后一项”的猜测。

### 记忆状态 `WordProgress`

- 按 canonical word ID 保存，每个独立学习项只有一份。
- 保存 FSRS 卡片状态、首次学习、最近复习、下次到期、成功次数、遗忘次数、连续成功和当前间隔。
- 到期队列、可提取率、单元进度和当前薄弱词从该状态计算。

### 学习会话 `StudySession`

- `selection`：当前分组或单元的顺序/乱序自由学习。
- `all`：全书乱序自由学习。
- `today`：到期复习优先，再补每日新词。
- `favorites`：收藏批量复习。
- `mistakes`：当前薄弱词专项复习。
- 顽固词专项：30 天内“忘记”达到 3 次或低评分达到 5 次时进入。
- `search`：用户从搜索结果建立的临时队列。

所有会话复用同一张单词卡和同一个评分事务。

## 统计口径

- 新学：该学习项第一次产生有效评分。
- 复习：已有学习记录的学习项再次评分。
- 完成次数：当天全部有效评分事件数。
- 覆盖词数：当天评分过的不同学习项数。
- 每日新词目标只约束“新学”，不截断真实显示值。
- 到期积压按梯度降低新词量，并保留最低量；关闭自适应即使用手动固定目标。
- 同词族只在当天埋藏新成员，次日可重新进入候选，不永久排除。
- 回忆耗时写入评分日志并给出快慢提示，不参与评分映射。
- 日历按覆盖词数着色，避免重复刷同一词抬高强度。
- 可提取率由 FSRS 根据卡片稳定性和距上次复习时间计算，不再用评分档位近似。

## 评分与撤销

- 四档评分继续使用“忘记、模糊、认识、熟练”。
- 评分后立即进入下一词。
- 提示条显示 5 秒，`Z` 在下一次评分前始终可撤销最近一次评分。
- 手机端提示条保留可点击的撤销按钮。
- 撤销恢复评分前的记忆状态、错词状态、队列位置和统计，并返回原词且保持释义展开。
- 撤销不回退收藏、设置和 AI 对话。

## 页面接入

### 学习

- 顶部展示会话类型和进度。
- 新增“今日任务”入口。
- 评分间隔显示学习引擎计算后的真实间隔。
- 搜索临时查看不计入学习，只有进入评分流程才产生记录。

### 词书

- 展示已学习、已掌握和待复习数量。
- 保留原有单元、顺序、乱序和全书入口。

### 词本

- 收藏和错词支持批量队列。
- 错词分为当前薄弱与历史错词；“已掌握”只解决当前薄弱状态，不删除历史。
- 顽固词连续 3 次“认识/熟练”后自动退出；30 天无新低评分也会退出，后续恶化时允许重新触发。

### 轨迹

- 分开展示新学、复习、完成次数和覆盖词数。
- “已到期”可直接启动到期复习。
- 日历详情标注每次评分是新学还是复习。

### 设置

- 每日新词目标保持原入口。
- 考研日期结合剩余词量、分组优先级和复习预留期预测每日工作量。
- 新增版本化 JSON 导出、导入和浏览器内自动快照。
- 导入前必须先备份当前数据，第一版只支持完整替换。

## 内容增强

- 优先级：音标、与当前释义一致的例句、翻译、2–4 个搭配。
- 每项内容记录来源；AI 生成内容必须明确标注并缓存在本地。
- AI 内容不自动写入人工确认的词族关系。
- 红宝书 66 个原文件保留在本地，通过 `audio-index.json` 按词定位，不生成 6550 个碎片。
- 两份 MP4 统一使用同一索引格式；其中的防倒卖声明片段不作为单词音频。
- 必考词 Unit 15 无法仅靠静音稳定分段，整单元暂用 TTS，等待后续强制对齐复核。

## 数据迁移

- v4 及更早评分历史按单词和时间排序，用 `ts-fsrs` 的 `reschedule` 重放并生成 v5 `WordProgress`。
- `忘记 / 模糊 / 认识 / 熟练` 分别映射 `Again / Hard / Good / Easy`，初期使用默认参数和 0.90 目标记忆率。
- 主学习状态从 `localStorage` 迁入 IndexedDB 分域仓库；数据库失败时才回退到旧存储。
- 保留收藏、错词次数、学习位置、乱序种子和设置。
- `passersby` 与 `passer-by` 继续归入 canonical ID 2506。
- 迁移前生成浏览器内自动快照。

## 实施顺序

1. v4 模型、迁移和纯函数测试。
2. 评分事务、动态间隔和撤销。
3. 今日任务与统计。
4. 收藏/错词批量队列和搜索。
5. 备份、自动快照与内容增强。
6. 页面、响应式、构建和迁移完成性验证。
