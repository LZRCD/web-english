## 0. 结论速览

1. **词环已领先、保持不动**：原声校对音频、离线 ECDICT、AI 例句生成与反馈重写、义项考频、例句生词反向收录、FSRS+撤销、本地数据安全、轨迹周报、性能诊断、三步引导（四款开源对标应用均无正式 onboarding，是差异化优势）。
2. **竞品差距集中在四类**：语境内容（真题/短文）、记忆方法（词根助记）、学习形态（测试/极速刷）、数据可视化（遗忘曲线/压力图）。
3. **开源生态的最大共性结论**：调度算法与业务事件分离、事件只增不改、统计全部由事件流派生——这是本项目的架构地基（T0），也是统计口径诚实化（ISSUE-CANDIDATE-01）的答案。
4. **统一路线图**：T0 架构地基 → T1 纯本地功能（6 项）→ T2 AI 功能（3 项）→ T3 学习体验与数据（真题例句 / 续练 / 打字模式 / 薄弱画像）→ T4 可选长期（同步 / PWA / 导出）。

## 3. 各提升点详情

### T0 架构地基（先于一切，低风险高杠杆）

**T0-1 事件溯源双表改造**〔源〕
- 参照 Anki revlog：`events`（append-only 事件流）与 `words`（当前态投影）分离。
- 事件 id 用毫秒时间戳（零冲突、天然时间序，单机 IndexedDB 完美匹配）。
- 事件分层谓词：`review`（推进 FSRS，影响调度）与 `lookup` / `guess_mistake`（只记账）分属两层；统计一律过滤只计影响调度的复习事件——「顺利回忆 95%」类指标不被查词/猜错污染（对应 lean-v3 ISSUE-CANDIDATE-01）。
- revlog type 取答题前状态，写库前快照「新旧间隔」，回放无需猜测语义。
- 事件模型：`events{id, wordId, kind, rating, intervalBefore, intervalAfter, difficultyAfter, takenMs, ts}` + `words{state, dueAt, stability, difficulty, lapses, streak}`。
- 裁剪过度设计：due 统一存 `dueAt: timestamp`；Suspended/Buried 家族退化为一个 `paused` 布尔；冲刺建模为**事件 + 过滤查询**，不进持久状态机；fuzz 分档退化为单调性约束。

**T0-2 冲刺会话 = 参数快照**〔源〕
- 进入冲刺：保存参数快照 → `get_retrievability` R 阈值或指定词本选词 → 每词 `next()` 提交并写 `session_id` 扩展字段 → 冲刺中 Again 的词自然进 Relearning 短间隔 → 结束恢复快照。
- 会话级可临时调低 `request_retention` 或关 `enable_fuzz`；提前复习完全合法（`elapsed_days` 按实际 last_review 计算）。

### T1 第一批：纯本地、低成本、高价值（无需 AI）

**T1-1 词汇量测试**〔竞 P0-1〕
- 新增 `app/components/VocabTestView.tsx`，入口放欢迎页 + 词本页顶部。
- 按红宝书词序分层抽样（每 100 词一层、每层抽 2-3 词，共约 60 题），自评「认识/不认识」+ 层位自适应（认识→更高层，不认识→更低层）。
- 结果页：估算词汇量 vs 考研目标（必考 1856 / 基础 3680 / 超纲 1014）覆盖缺口，「不认识」一键加入薄弱词队列/临时学习队列。纯本地，无 API。

**T1-2 极速刷词模式**〔竞 P0-2〕
- 新增 `app/components/QuickReviewView.tsx`：全屏大字卡 + 释义 + 发音，速度可调（2s/3s/5s）自动翻卡，只留「认识/不认识」两键。
- 认识→FSRS Good，不认识→Again（复用现有评分日志管线），结束后统计并一键加入薄弱词队列。入口：学习页设置区 / 词本「批量复习」旁。

**T1-3 文章批量提取生词**〔竞 P0-3〕
- 词本页新增「整篇提取」：粘贴文章 → 复用 `lib/word-utils.ts` 英文分词 → 去重 → **过滤已掌握词（FSRS 状态）** → 列表预览释义（批量 ECDICT lookup）→ 一键加入划词集/临时队列。

**T1-4 考义高亮 UI**〔竞 P0-4〕
- 现有义项考频（★/◐/·）数据已就绪，纯样式升级：高频义项加粗 + 浅底高亮，学习卡与查词弹窗一致生效，不改数据结构。

**T1-5 每日学习提醒**〔竞 P0-5 + 源 P3 ToastFish〕
- 设置页新增「学习提醒」区块：开关 + 时间选择 + Notification 权限申请（需用户手势触发）。
- 说明：纯本地应用，提醒仅在浏览器打开时生效（setInterval 检查）；权限被拒显示引导文案。
- 可选扩展（〔源〕）：通知内快速测试——退化为「每日提醒 + 通知内快速选择测试」。

**T1-6 遗忘曲线 + 复习压力图**〔竞 P0-6，口径依赖 T0〕
- 轨迹页 `HistoryView.tsx` 新增两图（纯本地，复用现有统计管线）：
  - 遗忘曲线：按周统计到期复习遗忘率（Again+Hard 占比）与可提取率折线。
  - 复习压力：未来 30 天到期复习量堆积图（按 FSRS due 逐日统计）+ 每日新词量线。
- 口径按 T0 事件分层谓词过滤；True Retention 口径参考 Anki：仅计影响调度且（Review 或 lastIvl≥1 天）的事件，ease==1 记失败其余成功，young(<21天)/mature(≥21天) 分桶。

### T2 第二批：需 DeepSeek，复用现有 AI 管线

**T2-1 词根词缀拆解 + AI 助记**〔竞 P1-7〕
- 新增 `app/api/etymology/route.ts`（仿照 `sense-frequency` 模式：DeepSeek 生成、IndexedDB 按词缓存、无密钥降级隐藏）。
- 返回 `{ breakdown, root, affixes[], mnemonic }`；WordCard 词族轨道下方新增「词根拆解 + 助记」卡片；划词弹窗复用。

**T2-2 长难句每日一句**〔竞 P1-8〕
- 复用 AI 管线：DeepSeek 生成考研真题风格长难句 + 主干/修饰/从句结构拆解 + 参考译文，按日期缓存 IndexedDB（当天只生成一次）。
- 展示：欢迎页或轨迹页顶部「今日长难句」卡片（含朗读），离线显示缓存句。

**T2-3 短文填词（词文串学）**〔竞 P1-9 + 源防泄题三件套〕
- 新增 `app/api/cloze/route.ts`：输入当日新学词（≤10 个）→ 生成 80-120 词短文，目标词挖空，返回 4 选 1 干扰项（同词性/形近，不得含目标词变形）。
- `QuizView.tsx` 新增「短文填词」题型：答对写 FSRS「认识」、答错写「忘记」并进薄弱词队列（复用现有专项测验管线）；按词组合（排序后拼接）key 缓存。
- 挖空实现可参照沙拉查词 `%contextCloze%` 思路（正则转义 + 等长下划线替换）；题目界面答案永不直接出现。

### T3 第三批：学习体验与数据

**T3-1 考研真题例句库**〔竞 P2-10〕
- 数据准备：`scripts/build-kaoyan-examples.mjs`，输入历年考研真题阅读文本（用户自备），提取含红宝书词的真题句 → 分片 JSON（`public/data/kaoyan-examples/`）+ 索引 manifest。
- WordCard 优先展示「真题例句」卡片（带年份来源标签），与 AI 例句并列；例句生词同样进反向收录。
- 考研场景含金量最高，但强依赖数据源质量，故排第三批。

**T3-2 复习会话续练**〔源 P2〕
- 参照 qwerty-learner `reviewRecords`：`{words, index, isFinished, createTime}` 持久化，中断可「继续当前进度」——本地应用最大流失点是复习到一半关掉重来。
- 与「任务长度可选（5/10/15/20）」配套（对应 ISSUE-CANDIDATE-04，ToastFish 默认做法）。

**T3-3 打字/默写模式 + 字母级错误**〔源 P3〕
- 参照 qwerty-learner：`timing[]`（每字母耗时）、`mistakes: {字母下标: 按错的键}`——给「拼写薄弱」维度提供客观信号，与四档主观评分互补。
- 默写成绩折算评分档位：全对=Good、错 1 次=Hard、错 2 次+=Again。

**T3-4 错词加权队列**〔源 P2〕
- 参照 qwerty-learner：`错误次数(0.6) + 最近错误时间(0.4)` 加权排序生成复习列表；与薄弱画像互补（画像产出「哪些词弱」，加权队列产出「下次先练哪些」）。

**T3-5 薄弱画像 lapse/leech 改造**〔源 P1〕
- 遗忘即降级：Again → `lapses += 1`、难度上升 → Relearning 短间隔（默认 10 分钟步）→ 走完步进回 Review，间隔硬性压回 1 天（`lapse_multiplier=0`）。
- 复发检测：`lapses >= 8` 且每过半阈值再触发（8, 12, 16, 20…）→ 打 `leech` 标签（= 薄弱词集，用户可见、可手动移除）。
- 数据模型：`{lapses 总数, 最近 lapse 时间, 当前连续成功次数}` 三元组替代单一 weakScore；查词/猜错视为「软 Again」只影响薄弱分/清零连胜，不强制重排。
- 薄弱降档 = 改配置不改数据：`tagParams: { 标签 → {requestRetention, w?, maximumInterval} }`，按词所属标签构造/切换 fsrs 实例。

### T4 第四批：可选 / 长期

**T4-1 本地优先同步（快照起步）**〔源 P2/P3〕
- 起步选 A：全量快照（saladict WebDAV 模式）——单文件 `{timestamp, words[]}` + ETag 304，LWW 时间戳新的覆盖，零后端（坚果云/gist 即可），几十行实现。
- 数据模型按 B 迁移条件预留：稳定 UUID id + `updatedAt`；将来接 PouchDB/CRDT 只加映射层，不改业务代码。
- 关键原则：本地为主、同步为辅；写库与同步解耦（write-through 钩子）。

**T4-2 PWA 真离线 + 数据导出**〔源 P3〕
- qwerty-learner dexie-export-import + ToastFish 会话日志：设置页放「导出学习数据 JSON」与「导出本周生词」。
- 模板化导出占位符：`%text% %trans% %context% %contextCloze% %note% %date%`，支持换行转义与 HTML 转义开关。

## 5. 执行顺序与依赖

1. **先 T0 后 T1**：遗忘曲线/压力图（T1-6）与薄弱画像（T3-5）的口径都依赖事件分层谓词；T0 是唯一动 IndexedDB schema 的批次，越早做迁移成本越低。
2. **T1 紧接 T0**：纯本地、无风险、当天见效，先建立可见价值。
3. **T2 再上**：复用 AI 管线，注意三层降级（LLM → IndexedDB 缓存 → 本地模板/规则），AI 是可选增强层不是数据通路。
4. **T3 依数据与意愿推进**：真题例句库等数据备齐；打字模式与错词队列可独立并行。
5. **T4 长期**：同步只做数据模型预留（UUID + updatedAt），功能等 T0-T3 稳定后按需推进。

## 6. 不建议做的（对个人考研场景价值低）

- 图片记忆（百词斩：内容成本高）
- 游戏 PK / 排行榜（无社交基础）
- 多端云同步强绑定（违背本地数据设计；T4-1 的同步只是可选的快照备份）
- 番茄钟 / 学习小组（非背词核心）
- Anki 式完整 Filtered/Preview/Cram 状态机（冲刺用事件 + 过滤查询即可）

## 7. 边界与保护项

- 两份来源文档均为只读调研结论；后续若选择任一方案实施，需按自动化迭代 SOP 重新授权并执行 Round 0。
- `1.txt`、`.zcode/`、架构文档、Typora 日志和历史运行日志保持保护项，不得暂存或修改。
- 任何 IndexedDB 结构变更必须版本化迁移、向后兼容、不删用户数据。
